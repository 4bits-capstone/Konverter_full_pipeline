Per-message cost estimate

┌────────────────────────────────────────────────┬────────────────┬───────────────────────┬────────────────────────────────────────┐
│                    Scenario                    │  Input tokens  │ Cost/turn (chat only) │ + voice-out (tts-1, ~600 chars/answer) │
├────────────────────────────────────────────────┼────────────────┼───────────────────────┼────────────────────────────────────────┤
│ Small doc, first turn (~2K token context)      │ ~2,000         │ ~$0.0003              │ +$0.009 → ~$0.009                      │
├────────────────────────────────────────────────┼────────────────┼───────────────────────┼────────────────────────────────────────┤
│ Large doc, first turn (max 60K-char budget)    │ ~15,000        │ ~$0.0023              │ +$0.009 → ~$0.011                      │
├────────────────────────────────────────────────┼────────────────┼───────────────────────┼────────────────────────────────────────┤
│ Mid-conversation, turn 5 (history accumulates) │ ~17,000–20,000 │ ~$0.003               │ +$0.009 → ~$0.012                      │
└────────────────────────────────────────────────┴────────────────┴───────────────────────┴────────────────────────────────────────┘

Notable: TTS dominates cost — synthesizing a typical answer (~600 characters) costs roughly 3–10x more than generating the text itself.
